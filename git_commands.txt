SDP SGA-2 - Git command log
==========================

Sources: commands recorded in the assignment chat and the saved PowerShell history for SDP_SGA2.
Repeated commands are listed where they ran. Independent checks in the same batch are grouped.
<author-name> and <author-email> stand for the supplied commit identity. Device codes are omitted.
Sections 1 to 9 cover the workflow through preparation of the original command log for review.
Section 10 ends at verification of the push of 7230154 to origin/main.
The commit and push of this extension fall after that checkpoint.

1. Initialize the repository and make the first commit
------------------------------------------------------

git --version
  Checked the installed Git version.

git rev-parse --show-toplevel
  Checked whether the folder was already part of a Git repository. Git found none.

git var GIT_AUTHOR_IDENT
  Checked the author identity Git would use. Git reported that an identity was missing.

git var GIT_COMMITTER_IDENT
  Checked the committer identity Git would use. Git reported that an identity was missing.

git init --initial-branch=main
  Initialized the repository with main as the initial branch.

git add -- index.html about.html
  Staged both HTML files for the first commit.

git -c 'user.name=<author-name>' -c 'user.email=<author-email>' commit -m 'Initial project setup'
  Attempted the first commit. The attempt failed because the sandbox denied access to .git/index.lock.

git -c 'user.name=<author-name>' -c 'user.email=<author-email>' commit -m 'Initial project setup'
  Retried with access to .git and created root commit d897384. The identity applied to this command.

git status
  Confirmed that main was active and the working tree was clean.

git log --oneline
  Showed the short ID and subject of the initial commit.

4. Merge feature into main
--------------------------

git status --short --branch
  Checked that feature was active and the working tree was clean before the switch.

git log --oneline --graph --all --decorate
  Showed feature at 3217ba4 and main at 32ad1a8 before the merge.

git merge-base --is-ancestor main feature
  Confirmed that main's commit was already an ancestor of feature's commit.

git config --get-regexp '^(merge\.ff|branch\.main\.mergeoptions)$'
  Checked for settings that could affect how the merge runs. Git found no matching settings.

git switch main
  Switched from feature back to main.

git branch --show-current
  Confirmed that main was active before the merge.

git merge feature
  Fast-forwarded main from 32ad1a8 to the existing feature commit 3217ba4.

git grep -n -A 1 -F 'Why Use Git Branches?' main -- about.html
  Searched the committed about.html on main and showed the heading and following paragraph.

git branch
  Listed both local branches and marked main as active.

git status
  Confirmed that the working tree was clean on main.

git log --oneline --graph --all --decorate
  Showed both branches pointing to 3217ba4 and displayed all three commits.

6. Demonstrate Git undo
-----------------------

git status
  Confirmed that main was active and clean before the temporary edit.

git log -1 --oneline --decorate
  Confirmed that HEAD pointed to main at 2c13477.

git diff -- index.html
  Showed the single temporary paragraph for review.

git diff --check
  Checked the unstaged edit for whitespace errors.

git status --porcelain --branch
  Confirmed that the unstaged index.html edit was the only pending change on main.

git rev-parse --short=7 HEAD
  Confirmed that 2c13477 was still the current commit.

git add -- index.html
  Staged the approved temporary paragraph.

git -c 'user.name=<author-name>' -c 'user.email=<author-email>' commit -m 'Add temporary paragraph for undo demonstration'
  Created c1eb090, which added one line to index.html.

git rev-parse HEAD
  Recorded the full ID of the temporary commit: c1eb090ae42a41a2c450271038abf3876913381e.

git rev-parse HEAD
  Confirmed that the recorded temporary commit was still current before reverting.

git status --porcelain --branch
  Confirmed that the working tree was clean on main before reverting.

git -c 'user.name=<author-name>' -c 'user.email=<author-email>' revert --no-edit c1eb090ae42a41a2c450271038abf3876913381e
  Created 4bc5adc with Git's default revert message. It removed the paragraph and preserved c1eb090.

git diff --exit-code 2c13477 HEAD -- index.html
  Verified that the committed index.html matched its version before the undo demonstration.

git show --format=oneline --no-ext-diff c1eb090ae42a41a2c450271038abf3876913381e HEAD -- index.html
  Displayed the original one-line addition and the revert's one-line deletion.

git status
  Confirmed that the working tree was clean on main after the revert.

git log --oneline --graph --all --decorate
  Showed the original temporary commit and its revert in the complete history.

  Confirmed that the documentation commit would follow the revert commit 4bc5adc.

git add -- git_commands.txt
  Staged the approved command log as the only file in the new commit.

git -c 'user.name=<author-name>' -c 'user.email=<author-email>' commit -m 'Document SDP SGA-2 Git commands'
  Created commit 7230154 on main using the supplied identity for that command.

gh api --hostname github.com user --jq '.login'
  Confirmed that GitHub authenticated the session as Kumkum-dev before pushing.

git remote get-url --push --all origin
  Rechecked the academic repository's push URL before sending the update.

git rev-parse main
  Resolved the full ID of 7230154 for comparison with the remote main tip after pushing.

  Resolved the full ID of 3217ba4 for comparison with the remote feature tip after pushing.

  Confirmed GitHub's main tip was 7230154 and its feature tip was 3217ba4.

  Confirmed the working tree was clean and main was up to date with origin/main.
